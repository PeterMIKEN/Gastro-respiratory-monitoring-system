5.1 Research Conclusion
This study successfully achieved the design, development, and testing of a wearable and remote gastro-respiratory monitoring system. The system integrated signal modeling, analog circuit design, embedded processing, and wireless communication into a unified biomedical prototype.
The MATLAB simulation phase demonstrated that gastrointestinal and respiratory signals can be realistically modeled using distinct frequency characteristics. The application of appropriate filtering techniques effectively isolated these signals, confirming the feasibility of separating physiological parameters based on frequency domains.
The transition from simulation to implementation was successfully realized using the ESP32 microcontroller. The system was able to receive simulated signals via Wi-Fi, process them in real time, and display them on a web-based dashboard. This validated the system’s capability for remote monitoring, which is a key requirement in modern healthcare systems.
The signal conditioning circuits, designed based on simulation parameters, provided adequate amplification and noise reduction. The use of a piezoelectric sensor model for gastric signals and a resistive sensor model for respiratory signals demonstrated the practicality of combining different sensing modalities within a single system.
The correlation analysis introduced in this study provided an additional layer of physiological insight by examining the relationship between gastrointestinal activity and respiratory patterns. Although tested using simulated data, the results showed that such analysis can be implemented in real time using embedded systems.
Overall, the system met all the stated objectives of the study. It demonstrated that a low-cost, portable, and integrated monitoring system can be developed using readily available components and modern embedded technologies. The project therefore confirms the feasibility of continuous, non-invasive gastro-respiratory monitoring in a wearable format.
